## Shared prompt

Use case: illustration-story. Asset type: two-panel cartoon for a high-school English idiom presentation. Create one very wide landscape diptych, aspect ratio 3:1, divided into exactly TWO EQUAL panels with a clean thin vertical white divider at the exact horizontal midpoint. Each half must be a complete readable scene, generous margins, no shared objects across the middle.
